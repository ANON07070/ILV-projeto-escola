# ILV — International Logistics Valve

> **Trabalho Escolar** · Site institucional desenvolvido como projeto acadêmico.

---

## 📋 Sobre o Projeto

Este repositório contém o site institucional da **ILV — International Logistics Valve**, empresa ficticia de logística automotiva internacional com sede em Santos, SP.

O site foi desenvolvido como **trabalho escolar** como parte final de um trabalho avaliativo de criação de uma empresa do zero.

---

## 🤖 Desenvolvido com IA

O site foi gerado e desenvolvido inteiramente com o do **Claude** (Anthropic), uma inteligência artificial assistente, a partir de briefings, slides institucionais e especificações fornecidas pelo autor do projeto.

Mais informações sobre o uso a IA estara no arquivo documentação.md
